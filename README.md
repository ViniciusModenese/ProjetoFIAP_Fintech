# Projeto FIAP Fintech

Este projeto foi desenvolvido para uma atividade da FIAP com foco na construção de uma interface de **Fintech**.

## Objetivo da atividade

Aplicar os conhecimentos de:

- HTML
- CSS
- Tailwind CSS

## Sobre o projeto

O layout apresenta uma dashboard financeira com:

- menu de navegação
- cartões de resumo financeiro (saldo, investido e fatura)
- tabela com últimas movimentações

## Abordagem responsiva

O projeto foi construído com abordagem **mobile first**:

- **Tela 1**: representa a versão mobile (base do desenvolvimento)
- **Tela 2**: representa a adaptação para dispositivos maiores
